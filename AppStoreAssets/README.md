# App Store 2.2 screenshot set

The promotional images in this folder are built from real XCTest screenshots of the shipping SwiftUI app. They use one consistent ink, jade, gold, violet, and coral art direction and contain no transparent pixels.

- `iphone-6.9-promo`: 1320 × 2868 PNG, six images
- `ipad-13-promo`: 2064 × 2752 PNG, six images

The source screens cover the skill effect presentation, advanced 9-choose-3 selection, illustrated skill guide, offline AI, mode selection, and local two-player skill deck. Rebuild them with `scripts/generate_app_store_promos.py` after exporting named XCTest attachments.
