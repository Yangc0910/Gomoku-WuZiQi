# App Store Assets

The screenshots in this folder are captured from the shipping app through UI tests. Files `01`–`03` cover the 1.1 classic and skill flows; files `04`–`05` were captured from 2.0 and cover the single-player setup and AI match experience.

`Tools/GenerateMarketingAssets.swift` is retained only as a legacy reference and must not be used to replace the 1.1 screenshots or app icon.
