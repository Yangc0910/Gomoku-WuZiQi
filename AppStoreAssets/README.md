# App Store Assets

The screenshots in this folder are captured from the shipping 1.1 app through UI tests. They remain valid for the classic and skill flows, but the 2.0 submission should add screenshots of the single-player setup and AI match experience.

`Tools/GenerateMarketingAssets.swift` is retained only as a legacy reference and must not be used to replace the 1.1 screenshots or app icon.

## Outputs

- `app-icon/app-icon-1024.png`: 1024 x 1024, no alpha, App Store icon preview
- `iphone-6.5/01-core-gameplay.png`: 1284 x 2778, portrait, no alpha
- `iphone-6.5/02-skill-mode.png`: 1284 x 2778, portrait, no alpha
- `iphone-6.5/03-match-setup.png`: 1284 x 2778, portrait, no alpha
- `iphone-6.9/01-core-gameplay.png`: 1320 x 2868, portrait, no alpha
- `iphone-6.9/02-skill-mode.png`: 1320 x 2868, portrait, no alpha
- `iphone-6.9/03-match-setup.png`: 1320 x 2868, portrait, no alpha
- `ipad-13/01-core-gameplay.png`: 2064 x 2752, portrait, no alpha
- `ipad-13/02-skill-mode.png`: 2064 x 2752, portrait, no alpha
- `ipad-13/03-match-setup.png`: 2064 x 2752, portrait, no alpha

The three screenshots cover classic gameplay and turn indication, both players' visible skill decks, and the redesigned skill-match setup screen. They match accepted App Store Connect screenshot dimensions for modern iPhone and 13-inch iPad uploads.

Reference: https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/
